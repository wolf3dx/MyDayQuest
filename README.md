# My Day Quest (M.D.Q)

Геймифицированный планировщик целей. Большая цель — это **лист (Quest)**, разбитый на **задания**, а задания — на **подзадания**. Из отмеченных заданий формируется **единый дневной план** (Главное окно) — не больше 4 задач за раз.

## Стек
- .NET 10 **MAUI** (Android / iOS / Windows / macOS)
- SQLite (локальное хранилище, sync-ready)
- CommunityToolkit.Mvvm, CommunityToolkit.Maui

## Возможности
- Листы: создание/удаление, лента наслаивающихся вкладок.
- Задания: пустое создание, экран деталей (название, даты, прогресс), подзадания с чек-боксами.
- Дневной план: чек-бокс у названия задания добавляет его в Главное окно (кнопка **QUEST**).
- Синхронизация через один файл `.mdq` (Save / Load / Sync) — для облачной папки (OneDrive/Я.Диск).
- Автообновление из GitLab Releases (иконка в шапке при наличии новой версии).

## Структура
- `Source/` — исходный код решения MAUI.
- `Release/` — актуальная готовая сборка.
- `Maket/` — макеты и описание.

## Сборка (Windows)
```
dotnet build Source/MyDayQuest -f net10.0-windows10.0.19041.0 -c Release
```
